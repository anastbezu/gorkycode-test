# Технические решения

Выбранные технологии и коротко — почему. Заполняется по мере принятия решений.

| Область | Решение | Почему |
|---|---|---|
| Язык и фреймворк | Python ≥ 3.11, FastAPI, Pydantic v2; слои `api / agent / services / db` | Pydantic-модели — одновременно контракт, валидация и документация API; асинхронные вызовы LLM |
| Доступ к БД | SQLAlchemy 2, Alembic, psycopg 3 | стандартный стек для FastAPI, миграции схемы |
| База данных | PostgreSQL + pgvector | записи, векторы и полнотекстовый поиск в одной базе |
| Поиск по старым записям | смысловой (pgvector) + полнотекстовый (конфигурация `russian`), фильтры SQL до поиска | понимает близкие по смыслу формулировки и разные словоформы |
| Агент | один вызов LLM на реплику: LLM выбирает действие и аргументы, код исполняет; состояние разговора хранит сервер | предсказуемо, меньше запросов к LLM |
| Даты и время | LLM выдаёт дату в ISO 8601 с часовым поясом, код проверяет; время не названо — «весь день» или уточняющий вопрос | без лишних зависимостей, без «тихой полуночи» |
| Пользователи | без авторизации, у каждого браузера свои записи и разговор | авторизация не входит в обязательные сценарии |
