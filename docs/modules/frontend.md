# Модуль Frontend

**Владелец:** Ася

## Цель и стек
Интерфейс голосового ассистента для управления личными задачами, встречами и напоминаниями.
Стек выбран легковесным и максимально производительным:
- **Технологии:** Native Modern ES6+ JavaScript (без тяжелых runtime-зависимостей), HTML5, CSS3.
- **Окружение развертывания:** Nginx Alpine (статика). В продакшене и локально собирается мгновенно без перегрузки CPU/RAM сервера.
- **Дизайн-система:** Полное соответствие дизайн-макетам Figma (`figma/`).

## Дизайн-система Figma
Вёрстка и стилизация строго следуют палитре и компонентам из Figma:
- **Официальная палитра:**
  - `Sun Glare` (`#DCFF00`) — яркий акцент, основная кнопка в тёмной теме, бейджи успешного создания, индикаторы дней с делами.
  - `Exuberant Orange` (`#FF5A24`) — кнопка действия в светлой теме, чипсы и предупреждения.
  - `Blue Violet` (`#6A5CC9`) — цвет пузырей пользователя, теги встреч.
  - `Cloud Dancer` (`#F2F0EB`) — фон в светлой теме, текст в тёмной теме.
  - `Darkest Hour` (`#1E1D1F` / `#121113`) — фон в тёмной теме, контрастный текст в светлой теме.
- **Атмосфера:** Плавные радиальные свечения на фоне в светлой и тёмной теме (`radial-gradient` на псевдоэлементах).
- **Стеклянный стиль (Glassmorphism):** Круглые кнопки действий (календарь, настройки, закрытие) с `backdrop-filter: blur(12px)`.
- **Компоненты:**
  - Карточки дел с бейджами (`Встреча`, `Задача`, `Напоминание · выполнено`).
  - Полоса 7 дней в едином контейнере с индикаторами-точками наличия дел.
  - Модальное окно настроек LLM с сохранением в `localStorage`.
  - Мобильная шторка «Мои дела» с жестом-ручкой (handle).

## Структура модуля `frontend/`
```
frontend/
├── index.html       # Базовая разметка: лента чата, панель «Мои дела», модалка настроек
├── style.css        # Дизайн-система по Figma (переменные, светлая/темная тема, адаптив)
├── dates.js         # Правила форматирования дат и времени по контракту data-model.md
├── api.js           # Взаимодействие с бэкендом (POST /api/chat, GET /api/items, X-User-Id)
├── app.js           # Логика пользовательского интерфейса, обработчики событий
├── test_dates.js    # Тесты форматирования дат и интервалов
├── Dockerfile       # Nginx Alpine для отдачи статики
└── .dockerignore    # Исключение лишних файлов при сборке образа
```

## Хранение состояния в браузере (LocalStorage)
Все клиентские данные хранятся в `localStorage` браузера и не теряются при перезагрузке страницы:
- `gorky_user_id` — анонимный UUID пользователя. Передается в заголовке `X-User-Id` во всех запросах.
- `gorky_conversation_id` — идентификатор текущего разговора (получается из ответа бэкенда).
- `gorky_chat_messages` — история сообщений чата (реплики пользователя и ответы ассистента со структурными результатами).
- `gorky_llm_config` — пользовательские настройки провайдера LLM (Base URL, Model Name, API Key).

## Ключевая логика
1. **Первый вход:** первый запрос к `/api/*` уходит без заголовка `X-User-Id`. Сервер выдает UUID в заголовке ответа и инициализирует 1000 стартовых записей. Клиент сохраняет UUID в `localStorage` и использует во всех последующих вызовах.
2. **Панель «Мои дела»:** запрашивает `GET /api/items` на период 7 дней вперед (`from`, `to`, `tz`, `include_undated=true`). Автоматически перезапрашивается после каждого успешного ответа чата.
3. **Обработка ошибок сети:** при обрыве или 5xx выводится честное сообщение о том, что статус выполнения неизвестен, и предлагается кнопка «Повторить» (перед повтором панель дел обновляется).
4. **Тема и адаптивность:** тема (светлая/тёмная) переключается автоматически по системным настройкам ОС (`prefers-color-scheme`). На экранах смартфонов (до 768px) панель дел трансформируется в нижнюю шторку.

## Запуск и проверка
### Локальный запуск через Docker Compose:
```bash
docker compose up frontend
```
Страница доступна по адресу: `http://localhost:3000`.

### Сборка Docker-образа:
```bash
docker build -t gorky-frontend ./frontend
```
