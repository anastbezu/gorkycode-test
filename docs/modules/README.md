# Модули

Как устроен каждый модуль: из каких частей состоит, как работает, какие решения приняты внутри и почему.

- Один файл на модуль: `agent.md`, `search.md`, `backend.md`, `voice.md`, `frontend.md`.
- Пишет владелец модуля, когда спроектировал решение.
- Обновляется в том же PR, что и код, который меняет устройство модуля.
- Границы с другими модулями здесь не описываются — они в [контрактах](../contracts/).
