# Статья

`gorky.pdf` — статья о GORKY: архитектура, агент, поиск, замер качества. Исходник — `gorky.tex`; графики берутся из отчёта бенчмарка `backend/eval/reports/agent-final/`.

Сборка — [Tectonic](https://tectonic-typesetting.github.io) (недостающие пакеты LaTeX скачивает сам):

```bash
cd docs/paper
tectonic gorky.tex
```
