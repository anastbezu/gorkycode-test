# Контракты модулей

Контракт — договорённость о границе между модулями: какие функции/эндпоинты есть, что принимают, что возвращают. Пока контракт не меняется, каждый может работать над своим модулем независимо.

**Правило:** любое изменение в этой папке — только по согласованию с техлидом (Родион) и с оповещением владельцев затронутых модулей.

| Файл | Граница |
|---|---|
| `data-model.md` | структура записей (задача / встреча / напоминание) |
| `api.md` | эндпоинты бэкенда, формат запроса и ответа чата |
| `agent-tools.md` | действия агента (tools) и их параметры |
| `search.md` | интерфейс поиска `search(query, filters)` |
