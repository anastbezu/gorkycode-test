# agent-06: состояние разговора в промпте, смена темы, отказ

**Исполнитель:** Давид. Делается сразу после [agent-03](agent-03-slot-filling-i-kontekst.md) и дорабатывает её.

## Цель
Модель понимает ссылки и поправки без истории сообщений: «вторую», «её», «нет, не в 15, а в 16», «верни». Для этого в промпт попадает короткий текст состояния разговора, а состояние обновляется после каждого действия.

## Контекст
- Контракты: [`data-model.md`](../contracts/data-model.md) — «Правила состояния» (`shown`, `focus_record_id`, `last_action`, `pending_skipped`, отказ); [`agent-tools.md`](../contracts/agent-tools.md) — `TargetRef` (`index`, `focus`, `text`, `when`) и «Правила» (даты и время). Пример реплики по шагам — [`architecture.md`](../architecture.md), раздел «Как обрабатывается реплика».
- **Что меняется относительно agent-03:** модель больше не передаёт `record_id` — id в промпт не попадают. Она ссылается номером из «Показано» или фокусом, id подставляет код.
- **Текст состояния в промпте** (без id, не больше 10 записей), например: `Показано: 1) Демо по сайту 22.10 10:00 2) Встреча с Иваном 22.10 15:00`; `Последнее действие: создана встреча «Встреча с Иваном» 22.10 15:00, в фокусе`; `Черновик: встреча «Встреча с Иваном», не хватает: start`.
- **Обновление после действия:** список, поиск и выбор перезаписывают `shown`; фокус — если затронута ровно одна запись; `last_action` — после создания, изменения, смены статуса.
- **Смена темы:** реплика не про черновик выполняется, черновик живёт ещё один ход (`pending_skipped`), к ответу добавляется напоминание о нём; следующая такая реплика его сбрасывает.
- **Отказ без LLM:** пока ассистент ждёт ответа или выбора, реплика целиком из списка («не надо», «забудь», «отмена», «проехали», «забей», «неважно», «отбой», «стоп») сбрасывает черновик без вызова модели.
- **Правила дат** из `agent-tools.md` — в промпт и описания полей: «в 3» = 15:00, части дня, «в следующую пятницу», «эта неделя» с понедельника, период без дня.
- **Транзакции:** один коммит на реплику, сервисы сами не коммитят ([backend-03](backend-03-izmenenie-status-konflikty.md)).

## Критерии готовности
- [ ] Текст состояния собирается из `ConversationState`; пустое состояние — ни строки; смоук-тест на сборку.
- [ ] Кейсы [`test-cases.md`](../test-cases.md) 3.11 (отказ) и 3.13–3.15 (смена темы) проходят; отказ не вызывает LLM.
- [ ] После списка `shown` совпадает с порядком в ответе; после одной записи — фокус.
- [ ] Кейсы раздела 9 (даты и время) проверены на живой модели; результат — в `docs/modules/agent.md`.

## На усмотрение исполнителя
Формат строк состояния, где собирается промпт, как определяется «реплика не про черновик».
