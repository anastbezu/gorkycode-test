# agent-07: изменить, выполнить, отменить, вернуть; несколько команд; справка

**Исполнитель:** Илья. После [agent-05](agent-05-integratsiya-s-servisami-i-api.md).

## Цель
Бонусные сценарии задания: перенос и изменение, «выполнено», отмена, откат, «нет, не эту, а ту»; две команды в одной фразе; ответ на реплику не по теме.

## Контекст
- Контракт [`agent-tools.md`](../contracts/agent-tools.md): действия `update_record`, `set_status`, `undo_last`, `help`, поле `replaces_last`, разделы «Цель изменения» и «Несколько действий», `ActionResult.restored`. Состояние — [`data-model.md`](../contracts/data-model.md). Сервисы изменения, статуса и конфликта — [backend-03](backend-03-izmenenie-status-konflikty.md); текст состояния в промпте — [agent-06](agent-06-sostoyanie-v-prompte.md).
- **Цель:** `index` → запись из `shown`, `focus` → `focus_record_id`, `text` + `when` → `search()` ([`search.md`](../contracts/search.md); до модуля поиска — твоя заглушка `search_by_substring`) среди активных записей, будущие в приоритете, затем ранжирование по точности (дата и время → время → название → нечёткое). Несколько кандидатов → ничего не менять, вернуть `candidates`, `awaiting="choice"`.
- **Отмена — сразу**, статус `cancelled`, ответ предлагает «верни». Подтверждение — только если команда задевает несколько записей («отмени всё на завтра»).
- **Откат:** `undo_last` и `replaces_last` используют `last_action.before`; откаченные записи — в `restored`.
- **Несколько вызовов:** все `create_record` из ответа модели (до трёх) — одним ответом; иное сочетание — первый вызов и просьба сказать остальное отдельно. Сначала проверь живым запросом, отдаёт ли Gemini несколько `tool_calls` при `tool_choice="required"`; результат — в `docs/modules/agent.md`.
- **Шаблоны ответов:** изменение, статус, откат, конфликт («в это же время у вас …»), группировка повторов в списке и поиске («Созвон с Севером — 7 раз, последний 22.08.2026»), справка с 2–3 примерами.
- **Транзакции:** один коммит на реплику (backend-03).

## Критерии готовности
- [ ] Кейсы [`test-cases.md`](../test-cases.md) раздела 7 и 8.5–8.9 проходят.
- [ ] «Нет, не этот, а тот» возвращает первую запись и меняет вторую одним ходом.
- [ ] Неоднозначная цель ничего не меняет до выбора.
- [ ] Смоук-тесты `pytest` на разрешение цели и откат без сети.
