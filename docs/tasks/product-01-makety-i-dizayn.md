# product-01: макеты интерфейса и дизайн в Figma

**Исполнитель:** Маша

## Цель
Спроектировать в Figma удобный веб-интерфейс голосового ассистента для задач и встреч (UI-кит, экраны, состояния и адаптив), который послужит точной визуальной основой для фронтенд-разработки Насти.

## Контекст
- **Концепция продукта:** Пользователь управляет личными задачами, встречами и напоминаниями естественной речью и текстом. Главный акцент — совмещение привычного диалогового формата (лента чата) со структурированными визуальными виджетами (карточки дел, боковая панель «Мои дела»).
- **Контракты данных для отображения:**
  - `ChatResponse` ([`docs/contracts/api.md`](../contracts/api.md)): сообщение ассистента состоит из текстового ответа (`reply`), структурного блока результата (`result: ActionResult`) и флага ожидания (`awaiting: "answer" | "choice"`).
  - `ActionResult` ([`docs/contracts/agent-tools.md`](../contracts/agent-tools.md)): содержит списки затронутых записей (`records`), кандидатов на выбор (`candidates`), информацию об ошибках.
  - Пользовательские настройки LLM (`docs/decisions.md`): адрес API, модель, ключ API (настройки хранятся в браузере).

### 7 обязательных экранов и компонентов в Figma:
1. **Главный экран (Чат):**
   - Лента сообщений: визуальное отличие реплик пользователя (справа) и ассистента (слева).
   - Поле ввода текста с кнопкой «Отправить».
   - Кнопка микрофона: два состояния — пассивное («Начать говорить») и активное («Идёт запись звука» с индикацией громкости/пульсации).
2. **Боковая панель «Мои дела»:**
   - Табы фильтрации: «Сегодня» / «На этой неделе» / «Все».
   - Карточки задач, встреч и напоминаний со временем, датой и признаком выполнения (активно / выполнено).
   - Список обновляется при выполнении действий в чате.
3. **Карточки результатов в ленте сообщений (`ActionResult`):**
   - Виджет созданной задачи / встречи (акцентный цвет, название, дата, время).
   - Виджет списка дел (компактный перечень внутри ответа ассистента).
   - Виджет найденной записи по поиску.
4. **Интерактивные чипсы выбора вариантов (`awaiting == "choice"`):**
   - Кликабельные плашки/кнопки под репликой ассистента, когда требуется выбор (например, ассистент спрашивает: «Какую встречу перенести? 1. Планёрка в 10:00, 2. Созвон в 14:00» — пользователь может кликнуть на карточку).
5. **Модальное окно / панель настроек LLM:**
   - Доступ по иконке «шестерёнка» в шапке приложения.
   - Поля ввода: `API Base URL` (плейсхолдер OpenAI / Gemini / OpenRouter), `Model Name`, `API Key`.
   - Кнопка «Сохранить» (значения живут в `localStorage` браузера).
6. **Индикаторы состояний ассистента:**
   - Состояние ожидания / размышления («Ассистент думает...», лоадер).
   - Состояние ошибки («Не удалось подключиться к серверу», кнопка «Повторить»).
7. **Мобильная адаптация:**
   - Вёрстка под экран смартфона: боковая панель «Мои дела» сворачивается в нижнюю шторку или выпадающее меню.

## Критерии готовности
- [ ] В Figma подготовлен проект со ссылкой для команды.
- [ ] Отрисованы все 7 обязательных экранов и компонентов.
- [ ] Определены базовая палитра (светлая/тёмная тема), типографика и отступы.
- [ ] Оформлены интерактивные состояния кнопок (hover, active, disabled).
- [ ] Показана адаптивная компоновка для экранов смартфонов.
