# devops-01: настройка сервера

**Исполнитель:** Настя

## Цель
Сервер готов принять приложение: `https://gorky.bond` открывается по HTTPS, сервер защищён, на нём есть Docker.

## Контекст
- Сервер: VPS, 1 ядро, 4 ГБ RAM, 10 ГБ NVMe, Ubuntu 24.04, IP `89.169.34.105`. Root-пароль — от Родиона.
- Домен: `gorky.bond` и `www.gorky.bond`. DNS переключает Родион — до этого сертификат не выпустится.
- Стек: Nginx + Let's Encrypt (certbot), Docker Engine + Docker Compose.
- Деплой приложения и база данных — не в этой задаче, они после выбора стека.
- Для выбора стека нужно знать, в какой стране сервер и доступны ли с него API OpenAI, Anthropic и Gemini.

## Критерии готовности
- [x] `https://gorky.bond` открывается без предупреждений браузера, `http://` и `www` ведут на него
- [x] сертификат продлевается автоматически
- [x] вход на сервер — только по ключу
- [x] снаружи открыты только SSH, HTTP и HTTPS
- [x] Docker и Compose работают
- [x] страна сервера и доступность API переданы Родиону
- [x] `docs/infra.md` описывает сервер

## На усмотрение исполнителя
Как именно настраивать сервер, защиту и Nginx (на хосте или в Docker).
