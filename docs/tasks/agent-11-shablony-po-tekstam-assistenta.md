## Цель
Все тексты, которые ассистент пишет в `reply`, — по документу Маши: даты словами, тип записи в подтверждении («Добавил задачу…», «Напомню…», «Добавил в календарь: …»), ошибки говорят, что сохранено, вопросы — только там, где ассистент ждёт ответа. ### Тексты сервисов не менять
Сервисы (`backend/services/records.py`) возвращают `ActionResult.error` — например «Такая запись уже есть — второй раз не создаю.», «Дата (start) уже в прошлом…». Эти же тексты показывают **кнопки «Моих дел»** (`/api/items`, 422 `detail`, backend-05). Поэтому:
- текст для чата собирает **агент** по виду результата, а не берёт `error` сервиса как есть;
- что нужно шаблону, уже есть в результате и действии: у дубля — найденная запись в `ActionResult.records`, у даты в прошлом — дата из действия модели;
- если шаблону не хватает признака (например, «это дубль» отличить от «это прошлое» только по тексту ошибки) — добавь признак в `ActionResult` **через техлида** (контракт `agent-tools.md`), а не разбирай строку ошибки.

### Что шаблон знает и чего не знает
Документ, раздел 1, факт 4: поля записи, число найденного, границы периода как даты. Слов пользователя о периоде шаблон не знает и род с названием не согласует — поэтому в шаблонах нет «был/была». Периоды словами («На этой неделе», «На выходных», «До 25 октября») — по датам `date_from` / `date_to` (раздел 4, таблица названий периодов). `date_to` не включается: называется последний включённый день.

## Тесты (pytest, без модели)
- **Правила раздела 13** — общий проверяльщик текста ответа: нет `ДД.ММ` и `ДД.ММ.ГГГГ`, нет эмодзи, markdown и вступлений, не больше одного «?», «?» есть только при непустом `awaiting`, лимиты слов по виду ответа, в ошибке сказано, что сохранено, слово типа согласовано с числом. Прогнать его по ответам всех тестов шаблонов.
- **Эталоны раздела 12** — для кейсов, где ответ однозначен по данным (создание, список, поиск, справка, ошибки, отказ, вопросы): фиксированное «сейчас» — среда 21.10.2026 10:00, записи — из стартового набора, действие модели подставлено. Ответ совпадает с эталоном строкой. Кейсы, помеченные в документе «условно», — по правилам раздела 13, без сравнения строки.
- **Дубль и прошлое** из чата — тексты раздела 5.4; те же ошибки через `/api/items` — прежний `detail` (кнопки не сломаны).
- Весь набор тестов зелёный.
