# frontend-05: действия с записями — создать, перенести, выполнено, удалить и вернуть

## Цель
Всё, что ассистент умеет голосом с записью, можно сделать руками: в карточке ответа, в «Моих делах» и в деталях записи в календаре — перенести, отметить выполненной, удалить с «Вернуть», а также создать новую запись.

## Контекст

### Что решено и почему
- Кнопки работают **без LLM**: отдельные эндпоинты поверх тех же сервисов, что у агента. Кнопка не шлёт фразу в чат — это был бы вызов модели на каждый клик и риск, что она поймёт не так.
- **Удаление мягкое**, как голосовое «отмени»: запись пропадает из списков, «Вернуть» возвращает её. Насовсем её стирает только чистка через 30 дней.
- **Пересечение не мешает сохранить**: запись сохранена, интерфейс предупреждает, как в чате.
- **Ручная правка не меняет разговор**: номера на экране остаются, лента не трогается. Сервер только забывает для этой записи последнее голосовое изменение, чтобы «верни» в чате не откатило её поверх ручной правки.

### Контракт — что важно клиенту
- `POST /api/items` (`CreateItem`) → 201, `PATCH /api/items/{id}` (`UpdateItem`, только меняемые поля) → 200, `POST /api/items/{id}/status` (`done` | `cancelled` | `active`) → 200. Ответ — `ActionResult`: запись в `records[0]`, пересечения в `conflicts`.
- Даты — со смещением пояса браузера (`2026-10-31T15:00:00+03:00`), параметр `tz` — пояс браузера; «весь день» — `time_given=false` и начало дня.
- 422 — `detail` сервера как есть («дата в прошлом», «такая запись уже есть», «нужно время»); 404 — записи уже нет (например, удалена на другом устройстве и стёрта) — обновить список.
- Ошибки двух видов уже различаются в `api/client.ts`: «результат неизвестен» и «сервер не принял» — для кнопок то же.

### Что уже есть
- Карточки — `components/ResultView.tsx`, «Мои дела» — `TasksPanel.tsx`, календарь — `CalendarView.tsx` ([`modules/frontend.md`](../modules/frontend.md)).
- Типы — `api/types.ts` (`Record`, `ActionResult`), добавить новые тела из контракта.
- Панель перезапрашивается после ответа чата; после кнопки — так же панель и календарь.

## Критерии готовности
- [ ] В карточке, «Моих делах» и календаре по макету: перенести (дата, время, «весь день», срок задачи), выполнено, удалить с «Вернуть», создать.
- [ ] После каждого действия панель и календарь показывают новое состояние; лента и номера в ней не меняются.
- [ ] Пересечение после переноса или создания встречи показано по макету.
- [ ] Ошибки 422 и 404 показаны текстом сервера; при сбое сети — «результат неизвестен», как в чате.
- [ ] На стенде: перенос встречи кнопкой, затем «Вернуть» после удаления, затем голосовое «верни» не трогает ручную правку.
- [ ] Тесты Vitest: сборка тел запросов (поля, смещение, «весь день»), обработка ответов и ошибок.
- [ ] `docs/modules/frontend.md` — раздел «Действия с записями».
