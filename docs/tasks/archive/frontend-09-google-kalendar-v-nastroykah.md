## Цель
Вошедший пользователь в настройках подключает Google Календарь одной кнопкой, видит, какой аккаунт подключён и всё ли в порядке, и может переподключить или отключить. После возврата со страницы Google — понятное уведомление. Гость этого блока не видит.

Плюс страница `https://gorky.bond/privacy.html` — её делаешь ты: без неё Google не даёт опубликовать приложение, а пока оно не опубликовано, подключиться может только команда — жюри увидит «доступ запрещён».

## Контекст

### Как работает подключение
Записи учётки сами попадают в отдельный календарь «Голосовой ассистент» в Google пользователя — в одну сторону, наши → Google. Другие календари пользователя приложению не видны. Синхронизацию делает сервер после каждой реплики; интерфейсу о ней ничего делать не нужно — если запись не ушла, ассистент сам пишет об этом в `reply`.

### Запросы
Все — с токеном учётки, через `api/client.ts`, как остальные (`headersFor`).

| Запрос | Ответ | Что делает интерфейс |
|---|---|---|
| `GET /api/calendar/google` | `{"state": "not_connected" \| "connected" \| "error", "email": str \| null, "error": str \| null, "pending": int}` | рисует состояние блока |
| `GET` → 403 | гость | блок не показывается (у гостя запрос вообще не слать) |
| `GET` → 503 | на сервере нет ключей Google | «Подключение пока недоступно на этом сервере», без кнопок |
| `POST /api/calendar/google/connect?tz=<пояс браузера>` | `{"auth_url": "..."}` | `window.location.assign(auth_url)` — уход на страницу Google в той же вкладке. `tz` — тот же пояс, что уходит в `/api/chat` (`Intl.DateTimeFormat().resolvedOptions().timeZone`) |
| `DELETE /api/calendar/google` | 204 | после ответа — снова `GET`, блок станет «Не подключён» |

«Переподключить» — тот же `POST /connect`.

### Состояния блока (набросок Маши)
1. **Не подключён** — пояснение («Записи будут появляться в отдельном календаре «Голосовой ассистент». Ассистент не видит ваши другие календари.») и кнопка «Подключить».
2. **Подключаю** — после нажатия, пока не пришёл `auth_url`: кнопка заблокирована («Открываю Google…»), чтобы не нажали дважды. Ошибка `POST` — сообщение рядом, кнопка снова доступна.
3. **Подключён** — почта (`email`; если `null` — просто «Подключён»), значок «Подключён», «Ждут отправки в Google: N» — только если `pending > 0`; кнопки «Переподключить» и «Отключить».
4. **Ошибка** (`state = "error"`) — почта, значок «Ошибка», текст `error` с сервера как есть (сейчас — «Доступ к Google Календарю отозван — переподключите.»), кнопки «Переподключить» и «Отключить»; `pending` — если больше нуля.
5. **Недоступно** (503) — только пояснение, без кнопок.

Где блок: в окне настроек, второй секцией под настройками модели; окно переименовать из «Настройки LLM» в «Настройки» (предложение Маши — по её фрейму). Статус запрашивать при открытии окна, не на каждой странице.

### Возврат со страницы Google
Сервер возвращает пользователя на `/?calendar=<значение>`. Интерфейс один раз показывает уведомление и убирает параметр из адреса (`history.replaceState`), чтобы оно не повторилось при обновлении страницы.

| `?calendar=` | Уведомление (черновик — финальный текст у Маши) |
|---|---|
| `connected` | «Google Календарь подключён. Записи на ближайшие 2 недели появятся в календаре «Голосовой ассистент».» |
| `no_access` | «Нужен доступ к календарю: подключите ещё раз и отметьте его на странице Google.» — галочка доступа там снята по умолчанию, её легко пропустить |
| `error` | «Не удалось подключить Google Календарь. Попробуйте ещё раз.» |

Вид уведомления — как остальные уведомления страницы (`Toast.tsx` или по фрейму Маши).

### Страница политики конфиденциальности
Сделать страницу `https://gorky.bond/privacy.html` — её адрес уже указан в настройках приложения в Google Cloud, менять его нельзя.

**Как устроить.** Файл `frontend/public/privacy.html` — самостоятельная страница, без React: Vite копирует `public/` в сборку как есть, nginx фронтенда отдаёт файл по `try_files $uri`, правки `nginx.conf` не нужны. Вид — в стиле сайта (шрифт, цвета, светлая и тёмная тема), читается с телефона.

**Что должно быть в тексте** — Google проверяет политику при публикации, поэтому пункты обязательны и должны быть правдой:
1. Кто мы: «Голосовой ассистент» (gorky.bond) — учебный прототип команды хакатона GORKYCODE; что делает ассистент.
2. Какие данные храним: записи (название, тип, даты, статус), состояние разговора, у учётки — логин и хеш пароля (сам пароль не хранится).
3. Кому передаём: голосовая запись — на распознавание речи и не сохраняется; текст запроса — языковой модели (Google Gemini), чтобы понять запрос.
4. **Google Календарь** — отдельный раздел:
   - доступ только к календарю «Голосовой ассистент», который приложение само создаёт (разрешение `calendar.app.created`), и к адресу почты Google — чтобы показать, какой аккаунт подключён; другие календари и события приложение не видит и не меняет;
   - туда уходят записи из ассистента: создание, перенос, отмена;
   - данные из Google не используются ни для чего другого, не передаются третьим лицам и не применяются для обучения моделей;
   - фраза о соответствии [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), включая требования Limited Use, — со ссылкой;
   - токен доступа хранится на сервере в зашифрованном виде и в браузер не передаётся.
5. Как удалить данные: отключить Google Календарь в настройках (доступ отзывается, токен удаляется) или в [настройках аккаунта Google](https://myaccount.google.com/permissions); данные гостя удаляются через 30 дней без запросов, отменённые записи — через 30 дней после отмены; удалить учётку и все записи — письмом на адрес из раздела «Контакты».
6. Контакты: адрес почты для запросов (какой — спроси у Ильи).
7. Дата обновления.

Если сомневаешься, правда ли пункт, — спроси Илью (календарь) или Дениса (хранение и сроки), не додумывай.

**Ссылка на неё с главной страницы** — обязательна: Google при публикации проверяет, что главная (`https://gorky.bond`) ведёт на политику. Скромная ссылка «Политика конфиденциальности» — в подвале, в окне настроек или в окне входа; где — по макету Маши или на твоё усмотрение.

Проверка: `https://gorky.bond/privacy.html` открывается и не подменяется главной страницей.

## Тесты
- Разбор ответа `GET`: каждое состояние → нужный вид блока; `pending = 0` — строки «Ждут отправки» нет; `email = null` — без почты.
- 403 → блок не рисуется; 503 → «недоступно» без кнопок.
- Параметр `?calendar=connected | no_access | error` → нужный текст уведомления, параметр убран из адреса; неизвестное значение — без уведомления.
- `connect` уходит с `tz` браузера.
