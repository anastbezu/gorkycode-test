# Спеки задач

Спека — описание пакета работ для одного модуля или человека. Отдавайте её своему AI-агенту вместе с [контрактами](../contracts/) и [правилами работы](../dev-guide.md).

Учёт задач (исполнитель, срок, статус) ведётся на доске YouGile; в карточке — ссылка на спеку.

| Спека | Модуль | Владелец | Статус |
|---|---|---|---|
| `agent-create.md` | агент: создание записей, даты, уточнения | Илья | в работе |
| `agent-read.md` | агент: список за период, поиск, ответы | Давид | в работе |
| `search.md` | поиск по смыслу | Родион | в работе |
| `backend-core.md` | хранилище, сервисы, API | Денис | в работе |
| `frontend.md` | страница чата, голос в браузере | Настя | в работе |
| `devops.md` | CI, деплой | Настя | в работе |

Новая спека создаётся по шаблону [`_template.md`](_template.md).
