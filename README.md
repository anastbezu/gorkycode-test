# Голосовой ассистент для задач и встреч

Прототип голосового ассистента: создаёт задачи, напоминания и встречи из свободной речи, показывает планы на период и находит старые записи по смыслу.

> **Статус:** в разработке. Стек и инструкция по запуску появятся после выбора технологий.

## Возможности
- создание задачи / напоминания — «Напомни мне завтра в 10 утра позвонить Ивану»
- создание встречи — «В четверг в 11 у меня встреча с дизайнером»
- список за период — «Что у меня на этой неделе?»
- поиск по смыслу — «Я когда-то ставил задачу по договору, найди её»
- уточняющие вопросы, если не хватает данных
